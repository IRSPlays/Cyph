WHAT A WIDGET CAN AND CANNOT DO

Honest limits, so the design matches what Android allows.

NO LIVE FACEA widget is a static picture the launcher redraws, not a running canvas. Each mood is a pre-rendered PNG of the same sprite (the pixel grid scaled up crisp). No blinking, no idle life. The face changes when the widget refreshes.
REFRESH IS SLOWAndroid limits how often a widget updates by itself. Plan changes, nudges, task steps and mute arrive as a push from the server (the same channel as the notifications), so they update at once. A clock tick is the only thing on a timer, once a minute at most.
BUTTONS ARE TAPSChips are real tap targets that send one command (snooze, stop, start) in the background. Nothing scrolls, no text entry. Talk and anything longer opens the app.
COLOUR = STATEGreen on schedule, amber a nudge or the next thing, teal the arm, blue study, grey offline. Same outline colours as the notifications so the two read as one system.
SAFE-BY-DEFAULTThe widget never shows message text, the pairing link or the Telegram content. Only plan titles and times, which the lock screen can hide.
NOT ANIMATEDNo Lottie, no GIF. If a size is wrong on someone's launcher, the same layout flexes: 4×2 collapses to the left tile plus one line.
