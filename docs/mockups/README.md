# Approved mockups (source of truth for the app UI)

Open `home-c2-corner.html` through any static server (`python -m http.server 8765 --bind 127.0.0.1` in this folder).
Pages: home-c2-corner (Home), calendar, memory, study (Study + Architect), study-desktop (Study mode: subjects, library and import, tutor, cards and review, past paper), study-devices (Study mode on phone, plus iPad notebook and freeform board), arm, settings, widget (desktop companion), phone, phone-widgets (4x2 + 2x2 home-screen widgets), phone-notifications (six notification kinds).
Shared: corner.css / corner.js (Corner look, nav, bottom-right buddy), bench2.css (tokens), cyph-engine.js + cyph-rig.js (live face), bench-common.js (mock data).
Rule: the bottom-right corner belongs to Cyph on every page; no UI under him.
